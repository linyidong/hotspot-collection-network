# T12 规划：平台侧信号源（v1.1）

- 日期：2026-10-21
- 目标：把线索从「B 级为主」推向 A 级 —— 补**平台/需求侧信号**（什么在卖、什么在涨、海外在搜什么），
  而不只是"新闻里提到了某个行业"。
- 约束：单用户本地、无需登录、无付费 API、零构建、不违反平台条款。

## 一、可行性实测（2026-10-21，本机直连）

| 候选源 | 方式 | 实测 | 结论 |
|---|---|---|---|
| **Google News RSS**（按关键词） | RSS | ✅ 200，标准 RSS | **可直接接** |
| **微博热搜榜** | JSON API | ✅ 200（需 `Referer: weibo.com`） | **可直接接** |
| **抖音热点榜** | JSON API | ✅ 200 | 可接（噪音大） |
| **百度热搜** | HTML 内嵌 JSON | ✅ 200 | 可接（需解析） |
| Amazon Best Sellers | HTML | ✅ 200，但为**JS 壳**，真实榜单需渲染 | ⏸ 需 headless，成本高 |
| AliExpress 热销 | HTML | ✅ 200，JS 壳 | ⏸ 同上 |
| TikTok Creative Center | HTML | ✅ 200，JS 应用 | ⏸ 需逆向接口 |
| Google Trends 每日 RSS | RSS | ❌ TLS 握手被阻断 | 暂不可用 |
| Temu | HTML | ❌ 证书校验失败 | 不可用 |
| Kickstarter / Indiegogo | HTML | ❌ 403 | 不可用 |
| B 站 / 知乎热榜 | API | ❌ 403 / 401 | 不可用 |

**结论**：能"零成本稳定拿到"的是 **Google News RSS（可参数化关键词）+ 微博/抖音热搜**。
Amazon/AliExpress 榜单要么上 headless 浏览器（慢、易被封），要么买第三方 API（超预算）。

## 二、分三期落地

### 一期（建议先做，0.5–1 天）

1. 新增源类型 `rss`（httpx + feedparser 直连）：
   - `gnews-kaobei`：Google News RSS `跨境电商`
   - `gnews-xuanpin`：`选品 爆款`
   - `gnews-guan-shui`：`关税 出海`
   - `gnews-platform`：`TikTok Shop OR Shopee OR Temu 政策`
   - `gnews-warehouse`：`海外仓 物流`
   （关键词可在 `data/config.json` 覆盖，不必改代码）
2. 新增源类型 `json`（微博热搜）：取前 50 条，带热度值；
3. 来源面板增加**类型标签**（新闻 / 平台 / 热搜），信号条沿用；
4. 粗筛提示词加一句：「平台/热搜类条目，请判断是否存在可操作的商品或需求缺口」；
5. 深加工候选的品类配额保持 3/类，避免热搜刷屏。

**验收**
- 5 个 Google News 源各 ≥10 条；微博热搜 ≥30 条；
- 一轮后至少 1 条线索卡的 `source` 来自平台侧源；
- 原有 9 源不受影响（仍 9/9）；
- 单轮成本增幅 ≤ ¥0.20。

### 二期（1–2 天）

- 接抖音热点榜、百度热搜（JSON 解析 + 热度阈值过滤）；
- 面板加「平台信号」分区（只显示 source_type=platform 的条目）；
- 粗筛对热搜类条目做「商品/需求」二分类，过滤纯娱乐八卦。

### 三期（可选，需你决策）

- Amazon Best Sellers / AliExpress 榜单：用 headless Chrome（本机已有）抓取，
  日更 1 次即可，不参与 3 小时轮次（太重）；
- 或改用第三方数据 API（付费，需你确认预算）。

## 三、已知盲点（一并修）

- **桥接源不吃单源代理设置**：财联社/东财/同花顺/金十/见闻RSS 由本地桥进程抓取，
  `proxy_mode` 只对直连源生效。T12 一期顺手把「代理说明」写进设置页，
  或后续给桥加 `?proxy=` 参数。

## 四、风险

| 风险 | 应对 |
|---|---|
| 微博/抖音接口随时变 | 适配器失败只记 last_error，不影响其他源 |
| 热搜噪音大、娱乐内容多 | 粗筛二分类 + 品类配额 + 事件去重 |
| Google News RSS 可能限频 | 每轮 1 次、5 个关键词分散；失败降级 |
| 成本上升 | 新增条目先进粗筛（便宜），深加工仍受 10 条/轮 + 品类配额限制 |

## 五、需要你拍板的一件事

一期先做**哪些源**？我的建议是：

**A 方案（推荐）**：Google News RSS 5 关键词 + 微博热搜 —— 纯新闻/趋势信号，稳、合规、成本低
**B 方案**：A + 抖音热点榜 + 百度热搜 —— 覆盖更广，但娱乐噪音明显上升
**C 方案**：直接上 Amazon/AliExpress 榜单（headless 抓取）—— 最贴近"什么在卖"，但最重、最易挂

> 我的判断：先用 A 跑一周，看线索质量有没有从 B 提到 A；不够再上 C。
