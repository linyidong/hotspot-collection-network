# 技术栈与选择理由

- 项目：Hotspot Collection Network
- 版本：v1.0（待用户确认）
- 日期：2026-10-19
- 前提约束：**用户只会「照教程装环境、跑命令」**；只在 Windows 本机跑；一条命令启动；预算 200 元/月。

---

## 1. 总览

| 层 | 选型 | 版本 | 一句话理由 |
|---|---|---|---|
| 语言 | Python | 3.11+ | 复用项目（china-finance-rss、TrendRadar）都是 Python，语言统一 |
| Web 框架 | FastAPI + Uvicorn | 最新稳定 | 自带 OpenAPI，写接口最省代码 |
| 数据库 | SQLite（stdlib `sqlite3`） | 内置 | 单人本地，零运维，备份=复制一个文件 |
| 定时 | APScheduler | 3.x | 进程内定时，不需要系统计划任务 |
| HTTP | httpx | 最新 | 支持异步与代理，一次搞定 |
| RSS 解析 | feedparser | 最新 | 成熟、容错强 |
| LLM 调用 | openai SDK（指向 DeepSeek） | 1.x | DeepSeek 兼容 OpenAI 协议，换 provider 只改 base_url |
| 前端 | 原生 HTML/CSS/JS（ES Modules） | —— | **零构建**，不需要 Node，改完刷新即见 |
| 图表 | ECharts（本地 vendor 单文件） | 5.x | 单文件引入，不依赖 CDN |
| 地球 | v1：Canvas 2D 贴图旋转 + 打点 | —— | 免 3D 依赖；three.js 留作 v2 可选增强 |
| 国内源桥 | `china-finance-rss`（子进程） | MIT | 现成、MIT、`python server.py` 即跑 |
| 日志 | `logging` + JSONL 文件 | 内置 | 人能读，也能用程序统计 |

## 2. 逐项理由与风险

### 2.1 Python 3.11+ 而不是 Node

- **理由**：`china-finance-rss` 是 Python，`TrendRadar` 也是 Python；全栈只用一种语言，用户只需装一次环境。
- **风险**：Windows 上 Python 环境变量容易出坑。
- **应对**：README 写死「安装时勾选 Add Python to PATH」，并在 `run.py` 启动时检查版本，低于 3.11 直接报中文错误。

### 2.2 FastAPI 而不是 Django / Flask

- **理由**：接口数量少（约 15 个），FastAPI 写起来最省；自带 `/docs`，出问题能自己点着测。
- **风险**：异步心智负担。
- **应对**：只在一个地方用异步（采集并发）；其余全部同步，避免 async 传染。

### 2.3 SQLite 而不是 PostgreSQL

- **理由**：单人、本地、数据量小（每天几百条）；备份 = 复制 `data/app.db`；不需要装服务。
- **风险**：并发写锁。
- **应对**：开 WAL 模式；所有写操作串行（单进程内一个写队列）。
- **风险**：JSON 字段查询弱。
- **应对**：加工结果整块存 JSON，不在 SQL 里查内部字段。

### 2.4 APScheduler 而不是 Windows 计划任务

- **理由**：跟着进程走，不需要用户配任务计划；错过轮次可在启动时补跑。
- **风险**：进程挂了就不跑。
- **应对**：`run.py` 带简单守护（异常不退出主循环）+ 启动时补跑；README 说明「电脑休眠会暂停」。

### 2.5 零构建前端而不是 React/Vue

- **理由**：用户不会维护构建链；`npm install` 一旦坏了就是灾难。原生 ES Modules + 单文件 ECharts，改完刷新即可。
- **风险**：页面逻辑写多了会乱。
- **应对**：按页面拆 `static/pages/*.js`，每页一个文件，单文件不超过 400 行。

### 2.6 Canvas 2D 地球而不是 three.js

- **理由**：v1 目标是「看起来像大屏」，不是「真三维」。Canvas 贴图旋转 + 经纬度打点，代码约 100 行，零依赖。
- **风险**：视觉上限低。
- **应对**：静态稿先给用户看，不满意再升级 three.js（记为可选任务）。
- **明确**：不做真 3D 是 PRD 的非目标，不是偷工减料。

### 2.7 提示词外置为文件

- **理由**：基准题要迭代 5 轮以上，提示词必须能改而不动代码。
- **做法**：`prompts/coarse.md`、`prompts/deep.md`，启动时读入；改完重启生效。
- **风险**：改了格式导致解析失败。
- **应对**：加载时校验必需段落，缺了直接报错并指出缺哪段。

## 3. 明确不引入的东西

| 不引入 | 原因 |
|---|---|
| Docker | 单人本机，多一层反而多一处坏 |
| Node / npm / 任何前端构建 | 用户不会维护，坏了难修 |
| Redis / 消息队列 | 单进程够用 |
| 向量数据库 / RAG | v1 不需要，且成本不可控 |
| ORM（SQLAlchemy） | 8 张表，写 SQL 更透明，少一层抽象 |
| 任何 GPL 代码 | 避免许可证传染（见 `reuse-decision.md`） |

## 4. 运行形态

```
python run.py
   ├─ 启动 china-finance-rss 子进程（127.0.0.1:8053）
   ├─ 启动调度器（08/11/14/17/20/23）
   ├─ 启动 FastAPI（127.0.0.1:9000）
   └─ 浏览器打开 http://127.0.0.1:9000
```

- 单进程为主；RSS 桥作为子进程，主进程退出时一并关闭。
- 不需要管理员权限，不需要开放防火墙端口（只监听 127.0.0.1）。
