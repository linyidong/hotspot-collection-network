# 赚钱案例库（三个金标准）

- 来源：用户口述的《对话 100 个搞钱自由人》访谈复盘
- 性质：**判断"什么算机会"的校准样本**，不是事实证据
- 声明：三个案例的收益数字（14 万订单、月入 14 万、月入 2 万+）均来自二手复盘，**无法核实，禁止作为项目指标或对外宣传**。本文只提取**可复用的动作结构**。

---

## 案例 1：04 年大学生 · 跨境 B2B 小额（手机支架/手机壳）

- 起点：旅行时发现同一件手机支架，国内进价约 10 元、当地售价 300 元
- 动作链：查海外进口数据找缺口 → 深圳找厂比价 → 学 FOB/EXW/DDP 出报价单 → AI 写开发信找采购商
- 关键：**无本金**（先拿订单再找货）、**无技术**（AI 做检索与文书）、信息差 = 供给差 + 语言差
- 瓶颈：找客户这一步最慢；报价与合规术语是门槛（AI 可代劳）

## 案例 2：失业 6 次的电商创业者 · 小红书平台内 B2C（一件代发）

- 起点：听说有人 0 粉丝两周做出结果，判断是信息差
- 动作链：选品（客单价 <50 元、面向女性）→ 一件代发不囤货 → AI 生成封面/标题（封面权重 70%，标题 30%）→ 笔记量产测试（约 20 多篇才出一条爆文）→ 挂购物车 → 前 50 单冷启动（满减券/新人券/抽奖）
- 关键判据：**先排除高退货率品类**（女装退货率约 50%，直接放弃）、**9.9 元起步**完成第一次成交
- 品类偏好：能帮人变美的、靠谱商家高性价比品、**非实物信息品**（求职表、秋招信息表——零成本、无物流、旺季爆发）
- 瓶颈：内容量产的执行力，不是创意

## 案例 3：63 岁退休阿姨 · 跨境小店（一件代发）

- 起点：不会英语、电脑基础弱，但发现 AI 翻译已够用
- 动作链：AI 查海外需求选小众刚需 → 国内一件代发 → AI 写标题/详情并翻译 → AI 生成图片 → AI 实时翻译并起草客服回复
- 关键：**语言门槛已被抹平**；每天 3–4 小时；不压库存
- 踩坑：初期跟风红海爆款，几个月零单；转向**小众刚需小件**后开始出单
- 瓶颈：持续上架与维护的执行力

---

## 三个案例的共性（这才是产品该抓的东西）

| 共性 | 含义 | 对产品的要求 |
|---|---|---|
| **零资金启动** | 一件代发/先单后货/数字信息品 | 输出必须标注"要不要囤货、要垫多少钱" |
| **AI 只做执行** | 翻译、写文案、做图、比价、发信 | 产品不做"替你想"，只做"替你跑腿 + 帮你判断" |
| **胜负手在选品** | 三个案例全部强调"选品优先于内容/运营" | 线索卡的核心字段是**品类**，不是新闻摘要 |
| **靠量试错** | 20 多篇笔记 / 几十封开发信 / 前 50 单 | 动作必须可批量执行，单次成本接近 0 |
| **避开红海** | 女装、大热爆款全部失败过 | 需要有"竞争度"判断，而不只是"需求存在" |

---

## 由此提炼的选品判据（补充进 playbook 的 S1）

原来的 S1 只看"需求增长 + 中国供给强"，不够。补四条：

1. **客单价**：优先 <50 元（国内平台）/ 单价差 ≥3 倍（跨境）；9.9 元可用于破零
2. **体积重量**：小件轻量，运费占比低
3. **退货风险**：非标服饰类退货率极高，慎入
4. **竞争度**：红海爆款不做，优先"小众刚需"
5. **是否可为数字品**：求职表、模板、资料包 —— 零库存、零物流、可无限复制

---

## 对产品定位的直接影响

1. **不只是"跨境"**：案例 2 是纯国内平台套利，同样符合"轻资产 + 信息差"。playbook 应泛化为**「轻资产电商套利」**，跨境只是其中一条路径。
2. **品类优先级高于新闻热度**：一条新闻如果落不到某个具体品类，对用户就是零价值——这一点在 v0.3 的实测里已经被验证（大量 S3 "成本信号"落不到品类）。
3. **"数字信息品"必须进 v1 的品类白名单**：它是唯一同时满足"零资金、零物流、可批量、AI 可代劳"的品类，而当前架构完全没覆盖。
