## 2. 本次新增内容

### 页面

- `static/stack.html`：技术栈展示页（单文件、自包含、无 CDN）
  - 架构总览 4 层：采集 → 处理 → 存储 → 展示/运维
  - 技术栈速览三 Tab：前端 / 后端 / 数据
  - 数据源矩阵：20 个源，可按类型筛选（直连 / RSS 桥 / RSS / 热搜 / 榜单快照）
  - 数据管线：6 段依次点亮的「跑一轮」模拟
  - 关键数字：8 个，滚动进入视口时递增
- `static/index.html`：顶部导航新增「技术栈」入口

### 验收与工具

- `tools/verify_stack_page.py`：内容/风格/响应式验收（11 项）
- `tools/verify_stack_interactive.py`：交互契约验收（16 项，真实点击 + 读 DOM 状态）
- `tools/make_preview_shots.py`：一键生成 README 预览图（headless 截图 → WebP）

### 预览图

- `docs/images/stack-interactive.webp`（默认态）
- `docs/images/stack-interactive-open.webp`（展开「处理层」+ 管线跑完）

## 4. 如何取用两个版本

```bash
# 克隆仓库
git clone git@github.com:linyidong/hotspot-collection-network.git
cd hotspot-collection-network

# 只看列表
git tag            # v0.1.0-base / v0.1.0-techstack

# 切到「含技术栈」版
git checkout v0.1.0-techstack

# 切到「之前的完整版」
git checkout v0.1.0-base

# 回到主线
git checkout master
```

> 分支说明：`master` 为开发主线；`release/techstack` 固定指向「含技术栈」版本，便于演示时直接取用。

---

## 5. 启动方式（两版一致）

Windows：双击 `启动.cmd`（或桌面快捷方式），菜单选 `1` 进大屏。
macOS：`./启动.command`，菜单选 `1`。

首次启动会自动检查 Python（≥3.11）、初始化数据库、拉起 RSS 桥（端口自动分配）。
