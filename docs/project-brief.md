# 项目简报：Hotspot Collection Network

- 版本：v0.1（阶段 1 访谈定稿）
- 日期：2026-10-19
- 状态：用户已确认（3D 地球走轻量版、指标盯金价/油价/汇率、机会类型按 6 类）
- 项目根目录：`D:\Deepseek Harness\Project\Hotspot Collection Network`

## 1. 一句话定义

一个跑在用户自己电脑上的「商机雷达」：每 3 小时自动扫一遍国内外经济类热点，先用便宜模型粗筛，再对少数条目深加工，把「谁在缺什么、缺口能否验证、下一步该干什么」直接摆到大屏上。

## 2. 目标用户

- **唯一用户**：项目所有者本人（个人工具）。
- 不做多用户、不做账号体系、不做权限分层。
- 使用场景：每天早上 + 每 3 小时一轮后打开看一眼；电脑常开，代理软件常挂。

## 3. 现状与痛点

| 项 | 现状 |
|---|---|
| 主要渠道 | Bloomberg、财联社、X、Reddit、雪球、YouTube、Instagram；ChatGPT 作为辅助 |
| 语种/地域 | 国内 + 国外都要，且倾向跨境 |
| 时间投入 | 每天 2 小时以上，且是「刷到停不下来」的成瘾式浏览 |
| 沉淀方式 | 备忘录记要点、收藏链接；碎片化、无结构、很少回看 |
| 已有的加工 | 会拿 ChatGPT 帮着理解，但每次都是人肉反复提问 |

**四个核心问题：**

1. **没有停止条件**：信息没有「今天看完了」的边界，只能一直刷。
2. **没有筛选**：99% 是噪音，少数有商机的条目被淹没。
3. **没有加工**：看到的是「发生了什么」，不是「谁在缺什么、我能做什么」。
4. **没有沉淀**：记了不回看，案例无法复用。

## 4. 核心价值与目标

把「2 小时成瘾式浏览」换成「**3 分钟看清这一轮有没有值得动手的事**」，并把值得的内容沉淀成可复用的案例。

**判断锚点（用户提供的真实样例）：** 越南手机壳案例——有人用 AI 查越南手机壳需求量与进关量，确认需求真实；再查中国出口量与越南采购商；用 AI 批量触达、讲优势、成交，赚跨境差价。

拆解为四步：`发现需求` → `用数据验证` → `找到对手方` → `用 AI 降低触达成本`。

**由此确定的「机会」标准：供需差能被数据证实，且动作可执行。** 不是行业分析，不是新闻摘要。

**机会库的性质：** 用户备忘录里存的是**别人已经做成的案例**，不是自己的点子。所以产品要回答的是「这套做法我能不能照抄」，而不是「预测未来」。

## 5. 机会类型 × 触发源

**6 类机会类型（v1 固定就用这 6 类）：**

1. 跨境贸易差价
2. 政策 / 补贴红利
3. 平台规则变化带来的套利
4. 新技术落地早期
5. 消费趋势
6. 供应链缺货

**3 类触发源：**

1. 国际形势
2. 国际政策
3. 国际事件引起的经济（石油涨价、黄金涨价、美国利率政策等）

交叉示例：`美联储高息（触发源）× 跨境贸易差价（类型）` → 美元走强 → 某类进口成本变化。

## 6. 首版范围（v1 必须实现）

| # | 功能 | 具体要求 |
|---|---|---|
| 1 | 监测大屏 | 中央地球（**v1 轻量版**：静态贴图 + 缓动旋转 + 热点打点）+ 新闻热点看板 + 数据波动看板 |
| 2 | 数据波动看板 | v1 盯三项：**金价、油价、汇率** |
| 3 | 定时采集 | 8–23 点每 3 小时一轮，无需干预；日志显示「抓了多少 / 筛出多少 / 花了多少」 |
| 4 | 一键采集 | 手动补一轮，5 分钟内出结果 |
| 5 | 增量视图 | 「最近 3 小时新增」与「更早」分区，新增条目有明显标记 |
| 6 | 机会解读 | 每条输出线索卡：一句话事实 + 机会类型（6 类之一）+ 谁在缺什么 + 一个可执行下一步 |
| 7 | 备忘录 + 收藏 | 系统内功能，挂在条目上，重启不丢 |
| 8 | 模型切换 | 粗筛模型 / 深加工模型可分别选，切换后成本可见 |
| 9 | 余额看板 | 按天 / 按轮 / 按模型看花费与剩余 |
| 10 | 源与代理分流 | 每条数据源可单独配「直连 / 代理」；国内源直连、国外源走代理，同一轮并行，**不需要用户手动开关代理软件** |
| 11 | 两种检索模式 | **v1 不调用 Search API**：计划式 = 按 6 类关键词对已抓到的新闻做订阅过滤（零成本）；漫游式 = 热榜抓取本身；外部搜索接口排 v1.1 |

## 7. 首版明确不做

- 不做多用户、登录、权限、支付。
- 不做移动端适配（先桌面大屏）。
- 不接抖音 / 小红书 / Instagram 作为数据源（抖音是灵感源，不是数据源）。
- **不实现代理软件本身**：订阅链接解析、节点管理、翻墙协议一律不做；只支持填写标准 HTTP/SOCKS 代理地址与端口。
- 不做自动下单、自动发邮件/私信（只做到「告诉你下一步做什么」）。
- 不做真 3D 地球（v2 再评估）。
- 不做自动交易、不做投资建议。

## 8. 数据源优先级

**用户优先级：** 财联社 / 雪球 → X → Bloomberg。
**选择原则：** 越不容易被封越好——先 RSS/公开接口，再网页抓取，最后才考虑登录态。

> 可获取性未经验证，必须在阶段 2 逐个实测后再定案，不提前承诺。

## 9. 成本模型

- 预算：约 **200 元/月**（必要时可上浮）。
- 折算：约 6–7 元/天，约 **0.9 元/轮**（按 **6 轮/天**：08/11/14/17/20/23）。
- 结构：**两级漏斗**——粗筛（便宜、全量）→ 深加工（贵、每轮限额）。
- 超限条目进「候选池」，不硬加工；用户可手动提级。
- 成本必须可见：按天 / 按轮 / 按模型三档。

## 10. 验收标准（v1 跑通）

1. 8–23 点每 3 小时自动跑一轮，无需干预；日志可见抓取量、筛选量、花费。
2. 大屏分「最近 3 小时新增」与「更早」，新增条目有标记。
3. 每条热点输出线索卡：事实 + 机会类型 + 谁在缺什么 + 可执行下一步。
4. 一键采集 5 分钟内补出一轮结果。
5. 备忘录与收藏可用，重启浏览器/电脑不丢。
6. 界面上可切换模型，切换后成本可见。
7. 余额看板可按天/按轮/按模型看花费。

## 11. 主要风险

| 风险 | 说明 | 处理 |
|---|---|---|
| 数据源可获取性 | Bloomberg 付费墙、X 反爬、财联社/雪球反爬 | 阶段 2 逐个实测，给结论不承诺 |
| 机会解读质量 | 极易退化成「正确的废话」 | 用越南手机壳案例做基准题，跑不通就调提示词 |
| 成本失控 | 全量深加工必然超预算 | 两级漏斗 + 每轮硬限额 |
| 合规 | 跨境网络接入的法律风险 | 只做标准代理配置，责任归用户 |
| 交付复杂度 | 用户只会装环境跑命令 | 一条命令启动 + 傻瓜 README，改配置走界面 |
