## 2. 已确认事实（有来源可核查）

- `sansan0/TrendRadar`：63,017 star，Python，**GPL-3.0**，2026-10-15 仍活跃，支持 35 平台 + RSS + AI 筛选 + 推送 + Docker + MCP。
- `yuxuan-made/china-finance-rss`：**MIT**，本地 `python server.py` 即可输出财联社/东财/同花顺/金十/华尔街见闻的 RSS。
- `ourongxing/newsnow`：**MIT**，自适应抓取间隔（最小 2 分钟）+ 缓存防封。
- 雪球**封直接 API**，必须走已登录 Chrome 的 CDP。
- X 自 2026-02 起改为**按量付费（credits）**，单价按 endpoint 在 Console 看，免费额度只给公共利益类应用。
- Bloomberg **不公布任何价格/套餐/配额**，销售合同制、无自助注册 → 个人不可行。
- DeepSeek 现价：flash 空闲输入 1 元/百万 tokens、输出 4 元；pro 空闲输入 4.5 元、输出 13.5 元；缓存命中仅为 0.02/0.15 元。Search/Fetch 各 5 元/1000 次。
