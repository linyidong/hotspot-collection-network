## 二、验收发现并修复的真问题

1. **代理地址不校验**：填「不是网址」也能保存 → 增加 `http(s)://` 校验（T-101）。
2. **废话拦截有漏洞**：`next_action = 建议关注该行业发展` 能通过校验 → r6 增加「关注/留意/观察/观望/跟踪动态/持续关注」词表（T-050）。
3. **跨批次重复**：同一新闻每轮都被重新粗筛/深加工 → `mark_duplicates` 增加近 7 天 `url_hash` 跨批次去重。
   - 实测批次 32：采集 420 → 去重后 **44**（此前 309）→ 粗筛 26（此前 190）
   - 成本 **¥0.60 → ¥0.29**，耗时 118s → 70s
4. **历史脏数据**：批次 16 因早期调试重复写入，清理 86 条（54 组）。
