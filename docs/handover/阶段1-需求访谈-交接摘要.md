## 2. 已确认事实

- 唯一用户是本人；个人工具，不做多用户/账号/支付。
- 每天现状投入 2 小时以上，成瘾式浏览；沉淀靠备忘录与收藏链接。
- 原始热点 + 每条机会解读，两层并存。
- 「机会」的判断锚点 = 越南手机壳案例：需求可被数据验证 + 动作可执行。
- 备忘录里存的是**别人做成的案例**，产品要回答「能不能照抄」。
- 每 3 小时一轮，8–23 点；必须区分「最近 3 小时新增」与「更早」。
- 系统内要有备忘录与收藏。
- 要能切换模型；要有付费余额看板（按天/按轮/按模型）。
- 国内源直连、国外源走代理，不允许要求用户手动开关代理软件。
- 数据源优先级：财联社/雪球 → X → Bloomberg，原则是「最不容易被封」。
- 3D 地球 v1 用轻量版；数据波动看板盯金价、油价、汇率；机会类型固定 6 类。
- 预算约 200 元/月，可上浮；用户能力为「会照教程装环境、跑命令」。

## 3. 我的推断（未经用户确认）

- 两级加工漏斗（粗筛 + 深加工）是预算内的唯一可行结构。
- 本地常驻服务比云服务更适合本场景。
- 「增量视图」能直接缓解成瘾式浏览，是产品的隐性价值点。
- 交付必须是「一条命令启动 + 傻瓜 README」，不能依赖用户改代码。
