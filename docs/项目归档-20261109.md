## 6. 项目整体业务逻辑

### 6.1 产品目标

一个运行在本机的「跨境商机雷达」：每 3 小时（08/11/14/17/20/23）抓取 20 个国内外财经/平台/榜单源，先用低成本模型粗筛，再对少量高潜条目做深加工，输出「事实 + 六类机会类型 + 谁在缺什么 + 钱流 + 可执行下一步 + 验证计划」的线索卡，用 3D 地球大屏呈现。

用户画像：个人、无本金/无资质/无团队、每天 4–6 小时；系统必须把“超出个人能力”的机会挡掉（r11 能力闸）。

### 6.2 数据流（一条主链路）

```text
08/11/14/17/20/23 调度 / 手动一键采集
  → 20 个源采集（api / rss / json / bridge / snapshot）
  → items 落库
  → URL 归一化 + 标题相似度去重
  → 生产硬过滤（早报/日报/综述/投关/答记者问/批复，0 模型费用）
  → 粗筛（deepseek-flash 并发）：
       is_economic / opportunity_type（6 类或 none）/ anchors / potential
  → 事件级 topic 合并
  → 取前 N（默认 10，按品类配额）做深加工
       ├─ 选中 → deepseek-v4-pro → 12 条校验 → 线索卡
       └─ 超出限额/预算熔断 → candidate_pool（cap 200）
  → 大屏线索卡 / 3D 地球 / 备忘录 / 收藏
  → 详情页可「深挖」：Tavily 检索 → DeepSeek 二轮 → 证据校验
```

### 6.3 关键阈值

- 每轮深加工上限：默认 **10**，可按品类配额。
- 候选池上限：**200**，超出按 potential 淘汰最低。
- 月预算：默认 **200 元**；剩余 <10% 停深加工，<2% 停所有模型调用。
- 12 条线索卡校验：r1 必填、r2 阶段、r3 anchor、r4 验证计划、r5 钱流、r6 交易动作、r7 事实禁传闻、r9 S3 数值、r10 反推测、r11 能力闸、r12 行业枚举、r8 认输。
- 六类机会：跨境贸易差价 / 政策补贴红利 / 平台规则变化带来的套利 / 新技术落地早期 / 消费趋势 / 供应链缺货。

### 6.4 组件与数据表

- `run.py`：入口、端口、桥、调度。
- `app/pipeline.py`：采集→粗筛→候选→深加工主流水线。
- `app/validate.py`：12 条校验。
- `app/deepdive.py` + `app/search.py` + `prompts/deepdive.md`：深挖。
- `app/opportunity.py`：六类枚举。
- `app/candidates.py`：候选池。
