# 人工必填参数与环境配置指南

- 项目：Hotspot Collection Network
- 版本：v1.0
- 日期：2026-10-19
- 原则：密钥只进 `.env`（不进仓库）；业务参数进 `data/config.json`（界面可改）；两者都不许硬编码进源码。

---

## 1. 人工必填参数清单

| 参数名 | 必填 | 类型 | 用途 | 从哪里获取 | 放在哪里 | 敏感 | 缺失时行为 |
|---|---|---|---|---|---|---|---|
| `DEEPSEEK_API_KEY` | **是** | 字符串 | 调用 DeepSeek（粗筛 + 深加工） | https://platform.deepseek.com → API Keys | `.env` | **是** | 启动不崩溃，页面显示「未配置密钥」并给出获取路径；不跑任何模型调用 |
| `DEEPSEEK_BASE_URL` | 否 | URL | 兼容其他 OpenAI 协议服务商 | 服务商文档 | `.env` | 否 | 默认 `https://api.deepseek.com` |
| `COARSE_MODEL` | 否 | 字符串 | 粗筛模型 | 服务商文档 | `.env` | 否 | 默认 `deepseek-flash` |
| `DEEP_MODEL` | 否 | 字符串 | 深加工模型 | 服务商文档 | `.env` | 否 | 默认 `deepseek-v4-pro` |
| `PROXY_DEFAULT_URL` | 否 | URL | 国外源的默认代理 | 用户自备代理软件（如 `http://127.0.0.1:7890`） | `.env` 或设置页 | 否（但可能含账号密码 → 视为敏感） | 国外源不可用，国内源正常 |
| `PORT` | 否 | 数字 | Web 端口 | —— | `.env` | 否 | 默认 8000 |
| `RSS_BRIDGE_PORT` | 否 | 数字 | china-finance-rss 子进程端口 | —— | `.env` | 否 | 默认 8053 |
| `MONTHLY_BUDGET_CNY` | 否 | 数字 | 月预算上限 | 用户决定 | 设置页 → `data/config.json` | 否 | 默认 200 |
| `DEEP_LIMIT_PER_RUN` | 否 | 数字 | 每轮深加工上限 | 用户决定 | 设置页 | 否 | 默认 10 |
| `RUN_INTERVAL_HOURS` | 否 | 数字 | 轮次间隔 | 用户决定 | 设置页 | 否 | 默认 3 |
| `ITEM_RETENTION_DAYS` | 否 | 数字 | 条目保留天数 | 用户决定 | 设置页 | 否 | 默认 90 |

> **不要**把 `DEEPSEEK_API_KEY` 写进 `data/config.json` —— 那个文件会被界面读写、可能被导出，密钥进去就会泄。

## 2. 配置分层

| 层 | 存放 | 谁能改 | 例子 |
|---|---|---|---|
| 秘密 | `.env`（已 gitignore） | 用户手工 | API Key、带密码的代理 |
| 部署参数 | `.env` | 用户手工 | 端口、base_url、模型名 |
| 业务参数 | `data/config.json` | 界面 | 预算、限额、间隔、保留天数、源开关 |
| 运行时输入 | 数据库 | 界面 | 备注、收藏、代理地址 |

**优先级**：`.env` > `data/config.json` > 代码默认值。冲突时以 `.env` 为准，并在日志记一条「被环境变量覆盖」。

## 3. 启动校验规则

启动时按顺序检查，任一失败给出**中文 + 怎么办**：

1. Python 版本 ≥ 3.11 → 否则提示「请安装 Python 3.11 或更高，安装时勾选 Add Python to PATH」
2. 依赖是否装齐 → 缺失时提示运行 `pip install -r requirements.txt`
3. `DEEPSEEK_API_KEY` 是否存在 → 缺失时**不退出**，页面显示引导（允许先看界面）
4. 端口是否被占用 → 提示改 `PORT` 或关掉占用进程
5. `prompts/coarse.md`、`prompts/deep.md` 是否存在且含必需段落 → 缺失时报出缺哪一段
6. `data/` 目录可写 → 否则报路径与权限问题

**禁止**：静默使用危险默认值（例如没有 Key 却假装跑起来了）。

## 4. 代理配置要求

- 只接受：`http://host:port`、`socks5://host:port`，可带 `user:pass@`。
- **不接受**订阅链接、`vmess://`、`ss://`、`trojan://` 等协议 → 输入即报错「本项目不解析订阅链接，请填写代理软件的本地地址」。
- 保存前测试连通性（TCP 连接 + 目标站点 HEAD 请求），失败则拒绝保存并给出具体原因。
- 代理地址里若含密码，日志与界面展示时必须打码（`http://***:***@host:port`）。

---

## 6. 换机器时的迁移步骤

1. 复制整个项目目录
2. 复制 `.env`（或重填）
3. 复制 `data/app.db`（历史数据）
4. `pip install -r requirements.txt`
5. `python run.py`
6. 打开首页 → `/api/health` 检查各源状态
