# 地球视觉 V2 设计（中央 3D 地球）

> 目标：把现在的「贴图球 + 光点」升级成有**昼夜、大气、景深、流光**的「监测地球」，
> 保持零构建、零 CDN、离线可跑，60fps 不塌。
> 结论来源见下「选型依据」；本文件只定方案，实现由 Trae 执行、DSH 验收。

## 一、选型依据（2026-10-20 核实）

| 候选 | 实情 | 决定 |
|---|---|---|
| gods-eye-view（MIT） | 原生 JS + **CesiumJS** + Google Photorealistic 3D Tiles，需 Google Maps Key（计费） | 不搬代码，只借视觉语法 |
| three.js | 项目已在用（0.149 UMD，vendor） | **继续作为渲染底子** |
| pixi.js | 2D WebGL 引擎 | 不用；粒子/光晕用 Sprite/Points 即可 |
| react-three-fiber | 需 React + 打包 | 不用；与零构建冲突 |
| remotion | React 渲染视频 | 不用；与实时大屏无关 |
| FFmpeg | 音视频转码 | 不用 |

**关键约束**：three.js r149 的 `build/three.min.js` 仍可用，但 `examples/js/*`（UMD 版后处理）
已在 r148 移除 → **不使用 EffectComposer/Bloom**，所有辉光用**加法混合 + 自发光贴图**实现。

## 二、视觉构成（自下而上 6 层）

| 层 | 名称 | 实现要点 |
|---|---|---|
| L0 | 星空 | 3 层景深 Points（近/中/远），不同尺寸与透明度，整体极慢自转；顶点着色器做大小与闪烁，避免逐点更新 |
| L1 | 地壳 | `ShaderMaterial` 昼夜混合：日间贴图 × 太阳照度 + 夜间灯光贴图 × 暗面权重；晨昏线用 `smoothstep` 软化（过渡带约 0.08 弧度） |
| L2 | 大气 | 双层：内层 `BackSide` + 菲涅尔（`pow(1-dot(N,V),3)`）加法辉光；外层半透明大球做外晕，`opacity≈0.10` |
| L3 | 网格 | 经纬线保留但降透明度（0.10→0.06），仅作空间参照，不抢主体 |
| L4 | 线索光点 | 按 stage 配色；**尺寸随潜力分**（10 时 0.6 倍，80 时 1.4 倍）；带呼吸脉冲环；`Sprite` 用代码生成的径向渐变贴图，加法混合 |
| L5 | 飞线 | 三次贝塞尔弧（起点→抬升→落点），线宽 1px；沿线一颗「流光点」循环移动；起点端小光晕 |

可选（P2，非本轮）：传感器滤镜（CRT/夜视）—— gods-eye-view 的做法是整屏 GLSL，我们可在
`renderer.domElement` 上叠一层 CSS filter + 扫描线，成本极低，留作后续。

## 三、太阳方位（决定昼夜）

- 用当日 UTC 时间 + 简易太阳赤纬/时角公式算太阳方向单位向量，每 60 秒更新一次。
- 失败时回退固定方向 `(1, 0.2, 0.3)`，**不得白屏**。
- 效果：地球自转时晨昏线随真实时间移动；上海白天时，美洲在夜里且城市灯亮。

## 四、交互

| 操作 | 行为 |
|---|---|
| 拖拽 | 旋转地球（保留现有） |
| 滚轮（仅在地球区域） | 缩放（保留 `el.contains(e.target)` 判定） |
| 悬停光点 | 光点放大 1.3 倍 + 显示「国家 · 阶段 · 潜力」小标签 |
| 点击光点 | 打开该线索卡详情（复用 `/static/detail.html?id=`，新标签） |
| 点击空白 | 取消选中 |

## 五、性能预算（必须满足）

- 桌面 1920×919 下 **≥50fps**（headless swiftshader 会低，以真机为准，headless 只做不崩验证）。
- 光点 ≤ 30 个、飞线 ≤ 12 条（超出按潜力截断）。
- `renderer.setPixelRatio(Math.min(devicePixelRatio, 2))`。
- 贴图总大小 ≤ 2MB（现有 1.2MB + 代码生成的发光贴图）。
- 页面加载到地球可见 ≤ 2.5s（本地 http）。

## 六、验收标准（DSH 实测）

1. 截图可见：昼夜分界、大气辉光、光点、飞线、星空，**无黑屏、无全黑球体**。
2. 6 个以上光点、4 条以上飞线，位置与 `country` 对应。
3. 悬停光点出标签；点击能打开对应详情页。
4. 滚轮在地球上缩放、在面板上滚面板（不回归）。
5. 昼夜方向随真实时间：改系统时间或注入 `?sun=` 参数后晨昏线位置移动。
6. 控制台无报错；`window.__fps5` 有值。
7. 不影响：大屏其它面板、拖拽换位、面板调尺寸、一键采集。

## 七、文件范围

- 改：`static/js/earth.js`（主体）、`static/index.html`（仅样式/容器如需）
- 不改：`app/**`、`prompts/**`、`third_party/**`、`.env`
- 不新增依赖，不引 CDN

## 八、风险

| 风险 | 应对 |
|---|---|
| 自定义 shader 在 swiftshader 下编译失败 | 提供 `MeshBasicMaterial` 回退分支；失败时仍是「贴图球」，不白屏 |
| 昼夜贴图混合过暗 | 日间乘数不低于 0.55，夜间灯光强度可调常量 |
| 光点点击与拖拽冲突 | `pointerdown/up` 位移 < 4px 才视为点击 |
| 60fps 达不到 | 减少星空粒子（3000→1200）、飞线降到 8 条 |
