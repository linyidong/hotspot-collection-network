# 机会模板 v0.1：跨境信息差套利

- 来源：用户提供的《对话 100 个搞钱自由人》第 95 期复盘（04 年大学生、无本金、AI + 跨境电商）
- 性质：**这是用户认定的「金标准」**，作为判断"什么算机会"的操作定义
- 重要声明：该案例是二手复盘（抖音），**其中"5 天出单、14 万订单、40% 利润"等数字未经核实，不得作为项目指标或宣传依据**。本文件只采用它的**流程结构**，不采用它的收益数字。

---

## 0. 一句话定义

**把海外需求带回国内找供给，把国内供给推到海外找买家，赚两者之间的信息差与执行差。**

关键前提（决定了普通人也做得成）：
- **不需要本金**：先拿到订单/意向，再找货、再发货。
- **不需要技术**：AI 承担检索、比价、写开发信、做报价单。
- **试错成本低**：一次选品验证只需查数据 + 发几十封开发信。

---

## 1. 四阶段 SOP

### S1 选品（找缺口）

**判断信号**（必须至少命中 2 条）：
1. 目标国该品类**进口额连续增长**（近 12–24 个月）
2. 中国是该品类**主要供给国**（出口占比高）
3. 目标国**本地供给弱**（无强势本土品牌 / 产能不足）
4. **终端价差 ≥ 3 倍**（海外零售价 ÷ 国内出厂价）
5. 体积小、重量轻、无强制认证壁垒（否则运费与合规吃掉利润）

**可查数据源**：UN Comtrade、各国海关统计、阿里国际站热搜、TikTok Shop / Shopee 类目增长榜、Google Trends。

**产出**：3 个候选品类 + 每个品类的 HS 编码 + 进口额与增速 + 价差估算。

**AI 可代劳**：查数据、算价差、列候选品类。
**AI 不能代劳**：判断哪个品类"你愿意做三个月"。

### S2 供应链（找货）

**动作**：1688 / 深圳周边工厂筛选 → 要报价（FOB/EXW）→ 批量比价 → 索取样品。

**判断信号**：起订量（MOQ）低、支持 OEM、有出口经验、报价低于目标零售价的 1/4。

**产出**：3 家备选供应商 + 报价单 + MOQ + 交期。

### S3 交易结构（把生意做成）

**要搞清的三件事**：
1. **贸易术语**：FOB（离岸价，买方付运费）/ EXW（出厂价）/ DDP（到岸完税）——新手优先 FOB。
2. **收款方式**：T/T 定金 + 尾款、或平台托管；信用证门槛高。
3. **单票成本表**：货值 + 运费 + 关税 + 平台费 + 汇损 → 反推最低售价。

**产出**：一份能直接发出去的报价单 + 单票成本表。

### S4 客户开发（找买家）

**动作**：找采购商 → 写开发信 → 跟进 → 拿到询盘 → 报价 → 成交。

**找客户渠道**：LinkedIn（按职位搜 Purchasing/Import Manager）、展会名录、Google Maps（按品类 + 城市）、平台 RFQ（阿里国际站/中国制造网）、目标国 B2B 黄页。

**开发信三要素**：一句话说清你能供什么 + 一个具体报价或样品承诺 + 一个低门槛的下一步（"要不要先寄样？"）。

**产出**：一份可复用的开发信模板 + 20 个具体联系人。

## 2. 热点 → SOP 的映射规则

这是**产品最核心的一步**：每条热点必须被判定"塞进哪一环"，塞不进就丢弃。

| 热点信号类型 | 命中阶段 | 下一步该做什么 |
|---|---|---|
| 某国某品类进口额/消费量增长、平台类目爆发 | **S1 选品** | 查该品类 HS 编码的进口额与增速，算终端价差 |
| 某国缺货、抢购、限购、供应链中断 | **S4 客户开发** | 找该国该品类的采购商，发开发信报价 |
| 关税调整、汇率异动、运价暴涨、认证新规 | **S3 交易结构** | 重算单票成本，判断哪个品类被"打通"或"堵死" |
| 中国产能过剩、出口转内销、工厂倒闭甩货 | **S2 供应链** | 找该品类工厂，要低价清库存报价 |
| 政策补贴（消费券/出口退税/产业基金） | **S1 或 S3** | 判断补贴落到哪个品类，谁因此有了购买力 |
| 新技术落地（某品类成本骤降） | **S1** | 判断是否出现新品类或替代品，价差是否打开 |
| 纯宏观数据、指数涨跌、人事变动、会议讲话 | **不命中** | **直接丢弃**，不进深加工 |

**规则：映射不到 S1–S4 任何一环的热点，一律判为「无可执行机会」。**

## 3. 输出格式（四件套升级为六件套）

在原有四件套基础上增加两项，否则无法判断"是不是生意"：

```json
{
  "fact": "一句话事实（≤60字）",
  "playbook_stage": "S1|S2|S3|S4",
  "who_lacks_what": {"subject": "谁", "need": "缺什么", "evidence": "依据"},
  "money_path": {
    "payer": "谁付钱",
    "receiver": "付给谁",
    "your_cut": "你赚什么（差价/佣金/服务费）"
  },
  "next_action": {
    "action": "24小时内可执行、直接推进交易的动作",
    "target": "具体对象（哪个海关数据/哪家公司/哪个平台）",
    "how": "怎么执行"
  },
  "verify_cost": {"money": "验证要花多少钱", "time": "要花多久"},
  "verifiable_data": ["具体可查的数据/指标"],
  "confidence": "high|medium|low"
}
```

## 4. 什么不算机会（否决清单）

出现任意一条 → 判 `rejected`：

1. **只有宏观数据，没有具体品类**（例如"美联储维持利率"、"国庆消费平稳"）
2. **下一步只能是「去查资料」**，而没有交易动作（查完要联系谁、报价给谁，必须写出来）
3. **需要牌照、资质或大额资金**（超出个人无本金模式）
4. **价差 < 1.5 倍**，或体积大/重到运费吃掉利润
5. **只能"关注"**，无法"联系"
6. **原文本身就是公告/投关记录/早报汇总**（没有新增信息，只是二手转述）

## 5. 对产品的影响

| 环节 | 变化 |
|---|---|
| 粗筛 | 只保留能映射到 S1–S4 的；映射不到的判 `potential ≤ 30`，不进深加工 |
| 深加工 | 必须填 `playbook_stage` 与 `money_path`；填不出 → 输出 `opportunity_type: none` |
| 校验 | 新增 r7（阶段必填且 ∈ S1–S4）、r8（money_path 三要素齐全）、r9（next_action 不得只是"查/查阅/下载/调取/阅读"） |
| 大屏 | 按阶段分组显示（选品信号 / 需求信号 / 成本信号 / 供给信号），而不是混在一起 |

## 6. 后续模板（v1.1+）

本文件只覆盖「跨境信息差套利」一类。用户关注的其余 5 类（政策补贴红利、平台规则套利、新技术落地早期、消费趋势、供应链缺货）暂时用**通用兜底模板**处理，输出时标注 `confidence: low` 与「模板未建」，避免假装成熟。
