代理只填本地代理软件地址（如 http://127.0.0.1:7897）；本项目不解析订阅链接。
代理怎么配才互不影响：
· 直连型源（见闻3频道 / 新浪 / Google新闻×5 / 微博）= 本页「直连/代理」按钮生效
· 桥接型源（财联社 / 东财 / 同花顺 / 金十 / 见闻RSS）= 由本地桥进程抓取（端口自动分配，默认 8053），不吃单源代理设置
· 平台榜单（Amazon）= 由本机 Chrome 抓取，也不吃单源设置
推荐做法：代理软件开「规则模式」（国内直连、国外走节点），本项目保持全部「直连」即可。
