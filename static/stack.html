架构总览（点击层查看详情）

1采集层
直连 APIRSS 桥热搜 JSON榜单快照（headless Chrome）
采集层覆盖 20 个数据源入口：直连上游 API、本地 RSS 桥（http.server 转发）、各平台热搜 JSON，以及用 headless Chrome 抓取的榜单快照。
2处理层
URL 去重事件相似度合并粗筛（deepseek-flash）深加工（deepseek-v4-pro）12 条结构化校验
处理层执行两阶段模型：先以 deepseek-flash 粗筛召回，再用 deepseek-v4-pro 深加工；全程先做 URL 去重与事件相似度合并，产出必须通过 12 条 结构化校验。
3存储层
SQLite（WAL）9 张表每日备份（保留 7 份）过期清理
存储层使用 SQLite（WAL 模式，9 张表）；每天自动备份并保留最近 7 份，配合过期清理控制体积。
4展示/运维层
FastAPI + uvicornAPScheduler 每日 6 轮预算熔断（软 10% / 硬 2%）
展示/运维层由 FastAPI + uvicorn 提供 API 与静态页；APScheduler 每日调度 6 轮采集；预算熔断设软限 10%、硬限 2%。
